# ✨ Daily Quotes – A Little Inspiration Every Day

A beautiful and responsive Daily Quotes application designed to inspire, motivate, and bring positivity to your everyday life.

🌐 **Live Demo:** [https://motivational-quotes-08kq.bolt.host](https://motivational-quotes-08kq.bolt.host)

## 📖 About the Project

Daily Quotes is a modern quote application where users can explore motivational and inspirational quotes, discover different categories, save their favorite quotes, and share meaningful words with others.

The application provides a clean, user-friendly interface with a responsive design for both mobile and desktop devices.

## 🚀 Features

- **Daily Inspiration:** Discover motivational and inspirational quotes.
- **Explore Quotes:** Browse and search quotes.
- **Categories:** Discover quotes based on different topics.
- **Favorites:** Save your favorite quotes for later.
- **Share Quotes:** Share inspiring quotes with others.
- **Quote Studio:** Create and customize quote images.
- **Personalized Settings:** Customize your app experience.
- **Responsive Design:** Works across mobile, tablet, and desktop screens.
- **Android Support:** Built with Capacitor for Android app packaging.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mohamedidris0429/motivational-quotes.git
```

### 2. Navigate to the project folder

```bash
cd motivational-quotes
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

## 📦 Android APK

The project uses Capacitor to package the web application as an Android application.

The Android project is available in the `android/` directory.
